ชมรมกรีฑา รร.นรต.ทำเนียบชมรมกรีฑา · since 1982 สืบค้นทำเนียบ

นโยบายความเป็นส่วนตัว

มีผลตั้งแต่วันที่ 14 ตุลาคม 2569 (ปรับปรุงเรื่องหน้าแก้ไขข้อมูลใน LINE)

ทำเนียบชมรมกรีฑา รร.นรต. ("ระบบ") ประกอบด้วยเว็บไซต์ค้นหาทำเนียบ หน้าค้นหาแบบละเอียดในแอป LINE (LIFF) และบัญชี LINE Official Account ของชมรม ("LINE OA") จัดทำโดยผู้ดูแลชมรมเพื่อให้สมาชิกติดต่อกันภายในชมรม ระบบนี้ไม่ใช่ระบบของทางราชการ

1. ข้อมูลที่เก็บ

ข้อมูลในทำเนียบ ของสมาชิกและศิษย์เก่าชมรม ได้แก่

  • รุ่น ยศ ชื่อ–นามสกุล ชื่อเล่นหรือฉายา
  • ตำแหน่งปัจจุบัน และประวัติตำแหน่งก่อนหน้า
  • เบอร์โทรศัพท์ และระยะหรือประเภทกีฬาที่แข่ง
  • หมายเหตุสำหรับผู้ดูแล (ไม่แสดงในหน้าค้นหา)
  • วันที่อัปเดตล่าสุด และช่องทางที่ใช้อัปเดต

ข้อมูลผู้ใช้ LINE OA ได้แก่ รหัสผู้ใช้ LINE (User ID) ชื่อที่แสดงใน LINE และสถานะการใช้งาน

บันทึกการแก้ไข ทุกครั้งที่มีการแก้ข้อมูล ระบบบันทึกว่าใครแก้ แก้ช่องไหน ค่าเดิม ค่าใหม่ และเวลา เพื่อให้ตรวจสอบย้อนหลังได้

หน้าค้นหาแบบละเอียดและหน้าแก้ไขข้อมูลใน LINE ไม่ได้อ่านหรือเก็บโปรไฟล์ รายชื่อเพื่อน หรือข้อความแชทของคุณ ตอนแก้ไขข้อมูล ระบบใช้รหัสยืนยันตัวตนจาก LINE เพื่อตรวจว่าเป็นผู้ใช้จริง และบันทึกว่าใครเป็นผู้แก้ สิทธิ์ "ส่งข้อความ" ใช้เฉพาะตอนคุณกดปุ่ม "ส่งเข้าแชท" เพื่อส่งการ์ดรายชื่อเข้าห้องแชทที่คุณเปิดอยู่เท่านั้น

2. แหล่งที่มาของข้อมูล

  • ทะเบียนรายชื่อเดิมของชมรม
  • ข้อมูลที่สมาชิกแจ้งหรือแก้ไขเองผ่าน LINE OA (รวมหน้าแก้ไขข้อมูลใน LINE) หรือแบบฟอร์มของชมรม
  • การตรวจสอบและแก้ไขโดยผู้ดูแลชมรม

3. วัตถุประสงค์

  • ให้สมาชิกค้นหาและติดต่อกันได้ เช่น ประสานงานกิจกรรมชมรม การแข่งขัน และงานรุ่น
  • ปรับปรุงข้อมูลในทำเนียบให้ถูกต้องและเป็นปัจจุบัน
  • ตรวจสอบการแก้ไขข้อมูล และป้องกันการใช้งานที่ไม่เหมาะสม

ระบบไม่นำข้อมูลไปใช้เพื่อการค้า การโฆษณา หรือขายให้บุคคลอื่น

4. ผู้ที่เห็นข้อมูล

  • ผู้ใช้ LINE OA และผู้ที่ได้รับลิงก์เว็บไซต์จากชมรม ค้นหาและเห็นข้อมูลในทำเนียบได้ ยกเว้นหมายเหตุสำหรับผู้ดูแล ผู้ที่เสียชีวิตแล้วจะไม่แสดงเบอร์โทร
  • ผู้ดูแลชมรมเห็นข้อมูลทั้งหมด รวมถึงหมายเหตุและบันทึกการแก้ไข
  • เว็บไซต์ตั้งค่าไม่ให้เครื่องมือค้นหา (เช่น Google) เก็บหน้าเว็บ

5. การจัดเก็บและผู้ให้บริการ

ข้อมูลเก็บใน Google Sheets และประมวลผลด้วย Google Apps Script ในบัญชีของผู้ดูแลชมรม หน้าเว็บให้บริการผ่าน GitHub Pages ซึ่งไม่ได้เก็บข้อมูลทำเนียบ การสื่อสารผ่าน LINE เป็นไปตามนโยบายของ LY Corporation

หน้าผู้ดูแลเก็บรหัสเข้าใช้ไว้ในเบราว์เซอร์ชั่วคราว (session storage) และจะหายไปเมื่อปิดแท็บ ระบบไม่ใช้คุกกี้เพื่อติดตามผู้ใช้

6. ระยะเวลาเก็บ

เก็บตลอดระยะเวลาที่ชมรมยังใช้ทำเนียบ หรือจนกว่าเจ้าของข้อมูลจะขอให้ลบ บันทึกการแก้ไขเก็บไว้เพื่อการตรวจสอบตามความจำเป็น

7. สิทธิของเจ้าของข้อมูล

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 คุณมีสิทธิ

  • ขอดูข้อมูลของตนเอง
  • ขอแก้ไขข้อมูลให้ถูกต้อง
  • ขอให้ลบข้อมูล หรือซ่อนเบอร์โทร
  • คัดค้านการใช้ข้อมูล

แก้ข้อมูลของตนเองได้ทันทีผ่านปุ่ม "อัปเดตข้อมูล" ใต้การ์ดใน LINE OA ส่วนเรื่องอื่น ๆ แจ้งผู้ดูแลผ่าน LINE OA ของชมรม หรือหยุดใช้งานได้ทุกเมื่อโดยบล็อกหรือลบเพื่อน LINE OA

8. การเปลี่ยนแปลงนโยบาย

ชมรมอาจปรับปรุงนโยบายนี้ และจะแสดงวันที่มีผลไว้ด้านบนของหน้านี้
